# Chatbot Analytics and Continuous Improvement Mockup

## Overview

This project demonstrates a simple **analytics pipeline for chatbot systems**.  
The goal is to monitor chatbot interactions, analyze user queries, and continuously improve chatbot performance by identifying new intents, FAQs, and query patterns.

The implementation uses a **console-based simulation (CLI)** where user interactions are logged and later analyzed to suggest improvements.

---

## Objectives

- Log all chatbot interactions
- Label a small dataset of user queries
- Analyze frequently asked questions
- Detect unknown queries
- Propose improvements for chatbot performance

---

## System Workflow

User Query
     ↓
Chatbot Engine
     ↓
Response Generated
     ↓
Interaction Logger
     ↓
CSV Log Storage
     ↓
Analytics Module
     ↓
Insights & Improvements
