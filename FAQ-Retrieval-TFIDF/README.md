# FAQ Retrieval using TF-IDF

## Description
A retrieval-based chatbot that uses TF-IDF vectorization 
and cosine similarity to find the most relevant FAQ answer.

## Concepts Used
- TF-IDF (Term Frequency-Inverse Document Frequency)
- Cosine Similarity
- Vector Space Model
- Information Retrieval

## Technologies
- Python
- scikit-learn

## How to Run
pip install scikit-learn
python faq_retrieval_tfidf.py
