# Intent Classification for Student Queries

## Description
A simple supervised NLP model that classifies student queries 
into predefined intent categories using TF-IDF and Naive Bayes.

## Intents Covered
- Admissions
- Exams
- Timetable
- Hostel
- Scholarships
- Fees
- Placements

## Technologies Used
- Python
- scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes

## How to Run
pip install scikit-learn
python intent_classifier.py
